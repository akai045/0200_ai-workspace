# 00_Inbox — 未整理の依頼

## 用途

まだタスクとして整理されていない依頼・思いつき・素材の一時置き場。

- 人間が思いついた依頼をとりあえず放り込む場所
- ここにあるものは「まだタスクではない」
- Planner補助（`05_Agents/planner-prompt.md`）を使って `02_Tasks/` のタスク定義へ昇格させる

## ルール

- ここに置いたものは正式なタスクではない。実行対象にしない。
- 整理が終わったら `02_Tasks/` にタスクを作り、ここからは消すかアーカイブする。
- タスク量が増えてトリアージが滞留したら、SPEC §3.5 に従い `inbox` ステータスの導入を検討する（フェーズ1では未導入）。
