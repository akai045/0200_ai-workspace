# security-check（セキュリティ検査）— 雛形

## 目的

成果物・変更を**セキュリティ観点**で検査する。

## 使うとき

- 認証・入力処理・外部連携・データ操作を含むタスク
- T2（不可逆・外部）タスクの検査工程

## 入力

- 対象コード・設定・変更差分

## 手順（雛形）

1. **秘密情報**（APIキー・パスワード・トークン）のハードコードがないか。
2. **入力検証**が境界で行われているか。
3. **インジェクション**（SQL・コマンド・XSS 等）の余地がないか。
4. **権限**（最小権限か、不要な外部送信がないか）。
5. **エラーメッセージ**が機微情報を漏らしていないか。

## 出力

- 検出事項を重大度（CRITICAL/HIGH/MEDIUM/LOW）付きで列挙。CRITICAL は着手前にブロック。

## 注意

- セキュリティ問題を見つけたら停止し、人間に報告する（`07_Policies/security` の方針に従う）。
- 露出した秘密情報はローテーションを促す。
