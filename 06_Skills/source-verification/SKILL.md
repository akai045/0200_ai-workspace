# source-verification（出典・根拠検証）

> **このスキルは必須**（SPEC §3.3）。§8 の監視指標「根拠なし記述率（1件以上で異常）」の背骨。

## 目的

成果物の各記述に**出典・根拠があるか**を検証し、根拠なき断定を排除する。
「事実」「推測」「意見」を混ぜて確定事項として出すことを防ぐ。

## 使うとき

- 調査・分析・文書・仕様案など、事実主張を含むすべての成果物
- Checker/Auditor に回す前の自己検証

## 主張の分類基準

各文を次の3つに分ける。

| 種別 | 定義 | 必要な扱い |
|------|------|-----------|
| **事実主張** | 検証可能な断定（数値・仕様・出来事） | 出典・根拠が必須 |
| **推測** | 未確認だが妥当と考える内容 | 「推測」と明示すれば可 |
| **意見／提案** | 設計判断・優先順位などの主張 | 根拠（なぜそう言えるか）を添える |

## 出典の格付け

- **一次情報**：実物・原典・実測・公式仕様。最優先。
- **二次情報**：要約・記事・伝聞。一次で裏を取れないか確認。
- 一次と二次は区別して書く。二次だけの断定は弱い。

## 手順

1. 成果物を文単位で上表に分類する。
2. 各**事実主張**について出典・根拠を確認する。
3. 根拠のない事実主張は、次のいずれかにする：
   - 出典を付ける
   - 「推測」と明示する（例：「〜と推測される」）
   - 削除する
4. 検証できなかった前提は成果物の**「未解決／引継ぎ」に集約**する。
5. 「根拠なし記述」が残っていないか最終走査する（目標：0件）。

## 出力テンプレート（指摘リスト形式で使う場合）

```
- 箇所: <引用>
  種別: 事実主張 / 推測 / 意見
  根拠: <出典 or なし>
  対処: 出典付与 / 推測と明示 / 削除
```

## チェックリスト（完了前）

- [ ] 事実主張すべてに出典・根拠があるか
- [ ] 出典のない断定を「推測」と明示または削除したか
- [ ] 一次情報と二次情報を区別したか
- [ ] 未確認の前提を「未解決」に明記したか
- [ ] 「根拠なし記述」は 0 件か

## 例

- 悪い：「ユーザーの多くは長期タスクを見落とす」（出典なしの断定）
- 良い：「本タスクの背景資料より、〜という課題が挙げられている（§背景）」（一次情報を明示）
- 良い（推測明示）：「しきい値〇〇は仮設定であり、実利用データでの較正が必要（未検証）」

## 禁止・エスカレーション

- 「たぶん」「一般的に」で事実を断定しない。
- 出典を確認できないものを確定事項として残さない。
- 根拠が揃わず判断できない場合は `blocked` にして人間へ確認。
