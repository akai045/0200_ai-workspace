# 06_Skills — 専門スキル

## 用途

専門知識を**着脱式スキル**としてパッケージ化する。必要なときに汎用シェル（Doer）へ読み込ませる。

- 1スキル＝1ディレクトリ＋`SKILL.md`
- 権限・文脈の隔離が必要になった場合のみサブエージェント化する（それまではスキルのまま）

## フェーズ1の初期スキル（7個）

| スキル | 用途 |
|--------|------|
| `requirements-analysis` | 要件整理 |
| `task-decomposition` | タスク分解 |
| `source-verification` | 出典・根拠検証（「根拠なし記述率」指標の背骨。必須） |
| `ui-ux-review` | UI/UX レビュー |
| `code-implementation` | 実装 |
| `qa-testing` | テスト |
| `security-check` | セキュリティ検査 |

## ルール

- 財務分析・ブランド文体・競合調査などは、実際に必要になってから追加する。
- **8個目以降のスキルは、必要が実証されるまで作らない**（SPEC §12）。
