# 09_Reports — 日次ブリーフ等

## 用途

人間が読むための**要約レポート**を置く。フェーズ1では手動生成。

- 朝のブリーフ（今日のタスク状況・承認待ち・blocked 一覧）
- 週次の振り返りなど

## 日次ブリーフ（非UI最小形）

- `daily/YYYY-MM-DD.md` に「今日の状況スナップショット」を置く。**ライブ表示は `HOME.md`（Obsidian/Dataview）**、こちらは日付で固定したプレーンMarkdownの記録（Obsidian無しでも読める）。
- 生成：`python tools/gen_daily_brief.py [YYYY-MM-DD]`（依存なし・ローカル完結）。数値は `02_Tasks/` の frontmatter から機械集計（手入力しない）。
- 将来、無人LOOP（ADR-0005）から呼び出して定期生成できる（クラウドは使わない）。

## ルール

- レポートは「読むための派生物」であって正本ではない。タスクの真実は `02_Tasks/` にある。
- 画面・ダッシュボードUI（§12ゲート）は作らない。ここはMarkdown生成のみ。
- Routine が生成する検査レポートは `09_Reports/` ではなく `10_Runs/` に追記する（SPEC §4.1）。
