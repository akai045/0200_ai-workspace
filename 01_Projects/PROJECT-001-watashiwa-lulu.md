# 概要
猫の里親探し・保護猫の譲渡・猫の飼い主コミュニティを行うサービス「わたしはルル」の公式サイトを新規制作する。00_Inbox/prompt01.md の依頼内容に基づく。

# 目的
- サービスの世界観（コンセプト・背景・願い）が伝わるブランドロゴを作る
- サイトマップ全6ページに対応するWordPressテンプレートを用意する
- 各ページのブラウザ出力イメージ（静的HTML）を作り、固定ページ・ブログ記事作成の参考にしてもらう

# スコープ / 制約
- やること：ロゴマーク＋コンセプト資料、WordPressテンプレート一式、各ページの静的HTML（プレビュー用）
- やらないこと：実際のWordPressサーバーへのデプロイ、独自ドメイン設定、決済・お問合せフォームの実送信設定（バックエンド接続は本番反映にあたるため対象外。フォームはUIのみ用意し、送信先は human が本番導入時に設定）
- 制約：外部送信・本番反映は行わない。すべて `03_Outputs/PROJECT-001-watashiwa-lulu/` 配下にローカル生成。ロゴは自作SVGベクターで作成（外部画像生成サービスは使わない）。
