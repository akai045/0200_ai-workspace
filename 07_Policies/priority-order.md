# priority-order — 指示が矛盾したときの優先順位

> SPEC §4.3。**低い階層が高い階層を上書きできない。**

---

## 優先順位（固定）

```
1. 法令・セキュリティ規定
2. constitution（共通規定）
3. プロジェクト要件
4. 個別タスク指示
5. エージェント固有マニュアル
6. 過去事例・議事録
7. AI自身の推測
```

---

## 運用ルール

- 上位と下位が矛盾したら、**必ず上位が勝つ**。
- 下位の指示で上位を上書きしようとする内容は無効。従わない。
- どちらが優先か判断できない、または上位同士が矛盾する場合は、**勝手に進めず停止して人間に確認**する（タスクを `blocked` にする）。
- 「AI自身の推測」（7）は最下位。推測で確定事項を上書きしない。根拠がなければ断定しない。

---

## 具体例

- タスク指示（4）が「本番へ直接反映してよい」と書いていても、constitution / 禁止事項（2）がそれを禁じていれば**従わない**。
- エージェント固有マニュアル（5）が受入条件を緩めても、プロジェクト要件（3）や個別タスク指示（4）の受入条件が優先される。
