# 05_Agents — エージェント定義

## 用途

Claude Code サブエージェント形式（YAML フロントマター＋本文）のエージェント定義を置く。

## フェーズ1の構成

| ファイル | 区分 | 役割 |
|----------|------|------|
| `knowledge-doer.md` | 基本 | 読み取り中心の実行役（調査・分析・文書） |
| `build-doer.md` | 基本 | 書き込み・実行の実行役（コード・テスト） |
| `checker.md` | 基本 | 成果物 vs 受入条件の独立検証 |
| `auditor.md` | 条件付き | T2 タスク専用の監査役（通常起動しない） |
| `planner-prompt.md` | 補助 | 依頼文からタスク下書きを作るプロンプトテンプレート（サブエージェントではない） |
| `_catalog.md` | 参考 | 18役割カタログ（将来の責任分離候補） |

## 原則（SPEC §2）

- エージェントは人格ではなく「文脈・権限の隔離装置」。数は最小にする。
- 専門性は人数ではなくスキル（`06_Skills/`）に持たせる。
- Doer は職種ではなく**権限境界**で分ける。
- `model` は性能クラスの別名（`haiku`/`sonnet`/`opus`）で指定し、将来差し替え可能とする。
