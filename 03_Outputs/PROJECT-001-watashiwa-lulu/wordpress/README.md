# 「わたしはルル」WordPressテーマ — 導入メモ

## ファイル構成
- `style.css` — テーマ本体のスタイル（テーマヘッダー必須項目を含む）
- `functions.php` — テーマ設定、CSS/フォント読み込み、メニュー登録
- `header.php` / `footer.php` — 共通ヘッダー・フッター
- `front-page.php` — トップページ（コンセプト・サービス概要・FAQ上位3件）
- `page-service.php`（Template Name: サービス内容詳細） — 料金・流れ
- `page-faq.php`（Template Name: よくある質問） — Q&A 7件
- `page-contact.php`（Template Name: お問合せ） — フォームの見た目のみ
- `archive.php` / `index.php` — お知らせ・ブログ一覧
- `single.php` — お知らせ・ブログの記事詳細
- `page.php` — 上記以外の固定ページ用フォールバック
- `images/logo.svg`, `images/logo-horizontal.svg` — ロゴ

## 導入手順（担当者向け）
1. このフォルダをZIP化し、WordPress管理画面「外観 > テーマ > 新規追加 > テーマのアップロード」から追加、有効化する。
2. 「設定 > 表示設定」で、新規固定ページ（例：「トップ」）を作成し、フロントページに指定する（`front-page.php` が自動適用される）。
3. 固定ページを3つ作成し、それぞれ「ページ属性 > テンプレート」で以下を割り当てる。
   - `/service/` → テンプレート「サービス内容詳細」
   - `/faq/` → テンプレート「よくある質問」
   - `/contact/` → テンプレート「お問合せ」
4. 「投稿」でお知らせ・ブログ記事を作成する（カテゴリ例：お知らせ／活動報告／猫のはなし）。一覧は `/blog/` 等のスラッグを持つカテゴリページ、または投稿一覧（`archive.php`）で表示される。
5. 「外観 > メニュー」でメインナビゲーション（トップ／サービス内容／よくある質問／お知らせ・ブログ／お問合せ）を作成し、「primary」の位置に割り当てる（未設定でも既定のリンクが表示される）。
6. ロゴは「外観 > カスタマイズ > サイト基本情報 > ロゴ」からアップロードすると `logo-horizontal.svg` の代わりに反映される。

## 注意（本タスクの対象外・要人間対応）
- **お問合せフォームの実送信**：`page-contact.php` は見た目のみで、送信処理は実装していない（本番反映にあたるため対象外）。Contact Form 7 等のプラグインでこの見た目を再現するか、送信先メールアドレスを人間が確認・設定した上で `wp_mail()` 処理を追加する。
- **本番デプロイ・ドメイン設定**：本テーマのサーバーへの反映、独自ドメインの設定は行っていない。
- 料金・FAQ等の文言はテンプレートに直接記述している（頻繁に変わらない想定のため）。変更する場合は該当PHPファイルを直接編集する。
