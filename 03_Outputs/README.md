# 03_Outputs — 成果物

## 用途

タスクが生み出した**確定成果物**を置く。

- プロジェクトごとにサブフォルダを切る（例：`03_Outputs/PROJECT-001/`）
- タスク frontmatter の `outputs:` が指すパスと一致させる
- 調査メモ、仕様案、UI改善案、比較資料など

## ルール

- Knowledge Doer は指定された成果物フォルダにのみ出力してよい。
- Checker は「成果物 vs 受入条件」を照合する。成果物自体を大きく改変しない。
- T0 の下書きは `scratch`（作業メモ）として扱い、正式成果物と区別する。
